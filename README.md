# 天堂旅行日记 · 纯前端体验版

为 REDcowork 等只支持纯前端作品的平台准备。此仓库不是原产品的后端部署版本，不依赖任何服务器、模型 API、数据库或密钥。

## 导入和部署

在支持 GitHub 的平台中连接本仓库，根目录为项目目录。运行配置：

- 安装：`npm install`（有 lock 文件时可用 `npm ci`）
- 开发：`npm run dev` 或 `npm start`
- 构建：`npm run build`
- 静态发布目录：`dist`
- Node.js：20.19 以上的 20.x，或 22.12 及以上

`dist` 是纯静态 HTML/CSS/JavaScript 和图片文件，可以托管在静态网站平台。Vite 仅是构建和本地预览工具，不是产品后端。

## 保留的功能

- 插画首页、呼吸和点击动效、四个导航页面。
- 默认预载大熊照片，无需自行寻找图片：基础卡通形象 → 用户确认 → 六个不同视角 → 确认建档。
- 预置真实原照、基础卡通形象、正面/侧面/背面/仰视/俯视/细节六视图、配套成品旅行明信片。
- 保留自传照片入口；自传照片只做原图与六格布局预览，不冒充实时 AI 生成。
- 宠物档案、生活照、修改/删除流程、微调要求记录。
- 大熊示例建档后收到配套成品明信片；首页邮筒显示未读，阅读后收进信夹。
- 信夹双列展示、放大、批量选择、下载和删除确认。
- 星星纸颜色、文字和图片、折叠及入瓶动效、历史记录和图片放大。
- localStorage / IndexedDB 保存当前浏览器数据。

## 明确的演示边界

- 页面运行时不调用 AI。大熊配套图片是在打包前通过项目现有模型 API 制作的，不是运行时生成。
- 大熊示例的基础形象和六视图为不同生成阶段；六视图是六个真实不同角度，不是同一图片重复六次。
- 自传照片保留原图，六视图仅为六格排版。只有大熊示例使用预置 AI 成品。
- 微调只保存用户要求，不会改变示例图片或实际调用模型，页面明确提示这个限制。
- 大熊示例明信片为预制成品，署名固定为“大熊”；更改示例名字不会改写图片内文字。自传照片的明信片为本地 Canvas 排版。
- 信夹中的两张初始明信片是随项目附带的示例图片。
- 定时和午夜传递只在页面运行/重新打开时检查，不会关闭后后台运行。
- 没有登录、跨设备同步、服务端存储、运营统计、支付或后台通知。
- 保存是浏览器下载或系统分享，不保证自动写入手机相册。
- 不要将任何模型密钥放入前端，前端代码及构建产物可被访问者读取。

页面内有“体验版 · 预置 AI 素材”说明入口。保留演示标识，避免将预置展示或原图排版误认为实时 AI 生成。

## 文件结构

- `index.html`：页面结构。
- `style.css`：插画定位、卡片、导航和动画。
- `app.js`：页面交互、本地状态及体验流程。
- `demo.js`：预置素材体验适配器，自传照片的本地排版预览。
- `public/assets/`：静态插画、图标和示例明信片。
- `public/assets/demo/`：大熊的原照片、基础形象、六视图、成品明信片及素材说明。默认照片由用户提供，裁剪后打包。
- `vite.config.js`：纯静态构建配置。
