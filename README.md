# 天堂旅行日记 · 纯前端体验版

为 REDcowork 等只支持纯前端作品的平台准备。此仓库不是原产品的后端部署版本，不依赖任何服务器、模型 API、数据库或密钥。

## 导入和部署

在支持 GitHub 的平台中连接本仓库，根目录为项目目录。运行配置：

- 安装：`npm install`（有 lock 文件时可用 `npm ci`）
- 开发：`npm run dev` 或 `npm start`
- 构建：`npm run build`
- 静态发布目录：`dist`
- Node.js：20.19 以上的 20.x，或 22.12 及以上

`dist` 是纯静态 HTML/CSS/JavaScript 和图片文件，可以托管在静态网站平台。Vite 仅是构建和本地预览工具，不是产品后端。

## 保留的功能

- 插画首页、呼吸和点击动效、四个导航页面。
- 上传宠物照片，基础形象预览 → 确认 → 六视图布局预览 → 确认建档。
- 宠物档案、生活照、修改/删除流程、微调要求记录。
- 建档后本地排版一张演示明信片；首页邮筒显示未读，阅读后收进信夹。
- 信夹双列展示、放大、批量选择、下载和删除确认。
- 星星纸颜色、文字和图片、折叠及入瓶动效、历史记录和图片放大。
- localStorage / IndexedDB 保存当前浏览器数据。

## 明确的演示边界

- 不调用 AI，也没有实际生图或一致性校验。
- 基础形象保留用户原照片；六视图是同一照片的六格排版，不是六个真实角度。
- 微调仅记录要求、重新排版，不会真实修改宠物形象。
- 首张明信片由浏览器 Canvas 使用用户照片排版，带有演示标记。
- 信夹中的两张初始明信片是随项目附带的示例图片。
- 定时和午夜传递只在页面运行/重新打开时检查，不会关闭后后台运行。
- 没有登录、跨设备同步、服务端存储、运营统计、支付或后台通知。
- 保存是浏览器下载或系统分享，不保证自动写入手机相册。
- 不要将任何模型密钥放入前端，前端代码及构建产物可被访问者读取。

页面内也有“纯前端体验版”说明入口。保留演示标识，避免将排版预览误认为真实 AI 生成。

## 文件结构

- `index.html`：页面结构。
- `style.css`：插画定位、卡片、导航和动画。
- `app.js`：页面交互、本地状态及体验流程。
- `demo.js`：纯浏览器演示适配器，本地图片和明信片排版。
- `public/assets/`：静态插画、图标和示例明信片。
- `vite.config.js`：纯静态构建配置。
